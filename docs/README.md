# Документация Glass

Glass — статически типизированный объектно-ориентированный язык, который делает видимым то, что другие языки прячут: как объект лежит в памяти, как работает виртуальный вызов и что делает сборщик мусора. Здесь — документация к языку, среде разработки и устройству проекта.

## Язык

Страницы идут по нарастающей: каждая опирается на предыдущие. Все примеры исполняются настоящей VM, а показанный вывод проверяется тестом.

1. [Основы](language/basics.md) — переменные, типы, операции, преобразования, вывод.
2. [Управление потоком](language/control-flow.md) — `if`, `while`, `for`, `range`.
3. [Функции](language/functions.md) — параметры, результат, рекурсия, передача аргументов.
4. [Строки](language/strings.md) — индексы, срезы, методы.
5. [Массивы](language/arrays.md) — литералы, срезы, методы, ссылки.
6. [Объекты](language/objects.md) — `mold`, наследование, `virtual`/`override`, `facet`, приведения, `toString`.
7. [Исключения](language/exceptions.md) — `try`, `catch`, `finally`, `throw`.
8. [Интроспекция](language/introspection.md) — `~layout`, `~vtable`, `~address`, `~heap`, `~gc`.

[Справочник языка](reference/language-reference.md) — все ключевые слова, типы, встроенные функции и методы с примерами (генерируется из тех же записей, что показывают подсказки в IDE). Полная грамматика — [`glass-grammar.md`](../glass-grammar.md).
