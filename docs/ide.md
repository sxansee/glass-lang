# Glass Studio

Glass Studio — среда разработки для Glass на Windows (WPF): редактор кода, пошаговый отладчик, визуализация памяти, курс по языку и журнал приложения. Запускается файлом `GlassStudio.exe` из [релиза](https://github.com/sxansee/glass-lang/releases) или из сборки проекта (см. [сборка и тесты](building.md)).

## Окно

| Панель | Что показывает |
|---|---|
| **Код** | редактор с подсветкой синтаксиса и номерами строк; щелчок на левом поле или `F9` ставит точку останова |
| **Вывод** | всё, что программа напечатала через `print` |
| **Ошибки** | ошибки разбора и типов с номерами строк; программа не запустится, пока они есть |
| **Журнал** | записи приложения с фильтром по уровню — см. [журнал](logging.md) |
| **Куча** | схема кучи: объекты и массивы как узлы, ссылки между ними как стрелки |
| **Вызовы и переменные** | стек вызовов и локальные переменные выбранного кадра; ниже — `static`-поля (`Mold.поле`, тип с пометкой `static`): они общие для всех кадров |
| **Инспектор объекта** | устройство выбранного объекта в памяти |

### Куча

Схема строится из снимка кучи на момент остановки программы. Цвета объясняет легенда под схемой: *объект*, *массив*, *мусор* (недостижим, освободится при сборке), *новый* и *изменён с прошлой паузы*, а также *локальная переменная — корень*, откуда сборщик начинает обход. Корнем бывает и ссылочное `static`-поле: оно подписано `static · Mold.поле` и стоит отдельной группой под кадрами — объект, который держит только оно, не мусор. Масштаб схемы — `Ctrl` + колесо, `Ctrl` `+` / `Ctrl` `-`, сброс — `Ctrl` `0`. Пока программа не остановлена, куча пуста: поставьте точку останова (`F9`) и запустите отладку (`F5`).

Кнопка **«Собрать мусор»** (меню «Отладка → Собрать мусор (~gc)») запускает сборку между шагами: объекты-«мусор» исчезают со схемы — это то же, что делает оператор `~gc` в программе (см. [интроспекцию](language/introspection.md)).

### Инспектор объекта

Выберите объект на схеме кучи или ссылочную переменную в таблице. Инспектор покажет **раскладку полей в памяти** (поле, тип, смещение, размер в байтах, значение), **таблицу виртуальных методов (vtable)** — какой метод какая реализация вызывает — и для массивов список элементов. Это те же сведения, которые дают операторы `~layout` и `~vtable`.

## Запуск и отладка

| Действие | Клавиши |
|---|---|
| Начать отладку / продолжить | `F5` |
| Запуск без отладки | `Ctrl` `F5` |
| Шаг с заходом (в вызываемую функцию) | `F11` |
| Шаг с обходом (функция выполняется целиком) | `F10` |
| Шаг с выходом (из текущей функции) | `Shift` `F11` |
| Остановить | `Shift` `F5` |
| Точка останова на строке курсора | `F9` |
| Карточка элемента под курсором | `F1` (или правая кнопка мыши над словом) |

Пока выполнение стоит, текущая строка подсвечена. Если после запуска вы изменили код, окно предупредит, что подсветка может не совпадать с выполняемой программой: остановите (`Shift` `F5`) и запустите заново.

## Файлы и примеры

Меню **«Файл»**: создать (`Ctrl` `N`), открыть (`Ctrl` `O`), сохранить (`Ctrl` `S`), сохранить как (`Ctrl` `Shift` `S`). В подменю **«Примеры»** лежат готовые программы по темам языка — удобная отправная точка.

## Курс и справка

- Пункт меню **«Курс по Glass»** (и кнопка на панели инструментов) открывает [интерактивный курс](course.md) рядом с редактором.
- Меню **«Справка»**: страница проекта на GitHub, **«Открыть папку журналов»** и **«О программе»** с версией.

## Карточка элемента кода

Правая кнопка мыши над словом (или `F1`, когда курсор стоит на нём) открывает карточку: что это за элемент, пример и ссылка на страницу документации. Карточка знает ключевые слова, типы, встроенные функции и методы, операторы `~`, числа и строки, а также **ваши** переменные (с типом), функции, `mold`, поля и методы: она работает по тексту, не запуская компилятор, поэтому отвечает мгновенно и на недописанном коде.

В карточке есть кнопки: **«Документация»** (страница в браузере), **«Копировать пример»**, **«Вырезать»**, **«Копировать»**, **«Вставить»** и **«Точка останова»** для строки под указателем. Для места, где подсказки нет (пробел, скобка), остаются только действия редактора. `Esc`, клик в другом месте или правка текста закрывают карточку.
