# Функции

Функция объявляется как `fn имя(параметры) -> тип { ... }`. Тип результата пишется после `->`; без него функция ничего не возвращает. Порядок объявления не важен: `main` может вызывать функции, описанные ниже.

```glass run
fn main() {
    print(twice(4))
    greet("Ада")
}

fn twice(x: int) -> int {
    return x * 2
}

fn greet(name: string) {
    print("Привет,", name)
}
```

```output
8
Привет, Ада
```

## Рекурсия

Функция может вызывать сама себя. Не забудьте условие остановки.

```glass run
fn factorial(n: int) -> int {
    if n <= 1 { return 1 }
    return n * factorial(n - 1)
}

fn fibonacci(n: int) -> int {
    if n < 2 { return n }
    return fibonacci(n - 1) + fibonacci(n - 2)
}

fn main() {
    print(factorial(10))
    print(factorial(20))
    print(fibonacci(15))
}
```

```output
3628800
2432902008176640000
610
```

## Как передаются аргументы

Числа, логические значения и строки передаются по значению: функция работает с копией. Массивы и объекты — по ссылке: функция видит и меняет **тот же** массив или объект.

```glass run
fn bump(n: int) -> int {
    n += 1
    return n
}

fn fill(xs: [int]) {
    xs.append(1)
}

fn main() {
    let k = 5
    print(bump(k), k)
    let a: [int] = []
    fill(a)
    fill(a)
    print(a)
}
```

```output
6 5
[1, 1]
```

## Типы проверяются до запуска

Неверный тип аргумента — ошибка компиляции, программа даже не стартует:

```glass error
fn add(a: int, b: int) -> int {
    return a + b
}

fn main() {
    print(add(1, "2"))
}
```

```output
1 ошибок типизации (тела функций):
  6:18: тип 'string' не совместим с ожидаемым 'int'
```

## Чего компилятор пока не проверяет

Компилятор не проверяет, что **все** ветки функции с `-> тип` заканчиваются `return`: на «пропущенной» ветке функция вернёт `null`, и ошибка проявится только потом. Пока что следите за этим сами. Это известное упрощение — оно записано в [`TODO.md`](../../TODO.md).
