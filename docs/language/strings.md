# Строки

Строка — значение типа `string`: неизменяемая последовательность символов Юникода, кириллица работает как есть. Литерал пишется в двойных кавычках; внутри допустимы `\n`, `\t`, `\"` и `\\`.

```glass run
fn main() {
    print("строка\tс табом")
    print("кавычка \" и слэш \\")
}
```

```output
строка	с табом
кавычка " и слэш \
```

## Склейка, повтор, сравнение

`+` склеивает (число с любой стороны превращается в текст), `*` повторяет, `==`, `!=`, `<`, `>` сравнивают.

```glass run
fn main() {
    print("ха" * 3 + "!")
    print("Ответ: " + 42)
    print("a" == "a", "a" < "b")
}
```

```output
хахаха!
Ответ: 42
true true
```

## Длина, индексы, срезы

`len(s)` или `s.length` — число символов. `s[i]` — символ с номером `i` (с нуля), отрицательный номер считается с конца. Срез `s[от:до]` берёт символы с `от` по `до - 1`; любая часть среза необязательна, а `s[::-1]` — переворот. Срезы устроены так же, как у [массивов](arrays.md).

```glass run
fn main() {
    let s = "Привет"
    print(len(s), s.length)
    print(s[0], s[-1])
    print(s[1:4], s[:3], s[3:])
    print(s[::-1])
}
```

```output
6 6
П т
рив При вет
тевирП
```

## Перебор символов

```glass run
fn main() {
    for ch in "abc" {
        print(ch)
    }
}
```

```output
a
b
c
```

## Методы строк

| Метод | Что делает |
|---|---|
| `upper()` / `lower()` | переводит в верхний / нижний регистр |
| `trim()` | убирает пробелы по краям |
| `contains(x)` | есть ли подстрока `x` |
| `startsWith(x)` / `endsWith(x)` | начинается / заканчивается на `x` |
| `indexOf(x)` | позиция первого вхождения или `-1` |
| `replace(a, b)` | заменяет вхождения `a` на `b` |
| `split(sep)` | разбивает на массив строк |
| `repeat(n)` | повторяет `n` раз |

Строка неизменяема: методы не меняют её, а возвращают новую.

```glass run
fn main() {
    let s = "  Привет, Мир!  "
    let t = s.trim()
    print(t.upper(), t.lower())
    print(t.contains("Мир"), t.startsWith("При"), t.endsWith("!"))
    print(t.indexOf("Мир"), t.indexOf("xyz"))
    print(t.replace("Мир", "Glass"))
    print(t.split(", "))
    print("ab".repeat(3))
}
```

```output
ПРИВЕТ, МИР! привет, мир!
true true true
8 -1
Привет, Glass!
["Привет", "Мир!"]
ababab
```

Обратное разбиению — метод массива `join`: `["a", "b"].join("-")` даёт `"a-b"` (см. [массивы](arrays.md)).
