# Массивы

Массив — упорядоченный набор элементов одного типа. Тип записывается в квадратных скобках: `[int]`, `[string]`, `[[int]]` (массив массивов). Литерал: `[1, 2, 3]`. Пустому массиву компилятор не может вывести тип, поэтому его нужно объявить: `let xs: [int] = []`.

```glass run
fn main() {
    let xs = [3, 1, 2]
    let empty: [int] = []
    print(xs, empty, len(xs), xs.length)
    print(xs[0], xs[2], xs[-1])
    xs[0] = 10
    print(xs)
}
```

```output
[3, 1, 2] [] 3 3
3 2 2
[10, 1, 2]
```

Индексы начинаются с нуля, отрицательный — отсчёт с конца (`xs[-1]` — последний элемент). `len(xs)` и `xs.length` — одно и то же. Выход за границы — ошибка выполнения с номером строки:

```glass run
fn main() {
    let xs = [1, 2, 3]
    print(xs[5])
}
```

```output
Ошибка выполнения: main:3: индекс 5 вне границ массива (длина 3)
```

## Срезы

`xs[от:до]` — **копия** части массива (правая граница не входит). Любую часть можно опустить, третье число — шаг: `xs[::-1]` — развёрнутая копия.

```glass run
fn main() {
    let xs = [10, 20, 30, 40, 50]
    print(xs[1:3], xs[:2], xs[3:])
    print(xs[::2], xs[::-1])
}
```

```output
[20, 30] [10, 20] [40, 50]
[10, 30, 50] [50, 40, 30, 20, 10]
```

## Методы

| Метод | Что делает |
|---|---|
| `append(x)` | добавляет элемент в конец |
| `pop()` / `pop(i)` | убирает и возвращает последний (или `i`-й) элемент; из пустого массива — ошибка |
| `insert(i, x)` | вставляет `x` на место `i`, остальные сдвигаются |
| `remove(x)` | убирает первый элемент, равный `x`; если такого нет — ошибка |
| `contains(x)` | есть ли элемент |
| `indexOf(x)` | индекс первого равного элемента или `-1` |
| `reverse()` | разворачивает массив на месте (развёрнутую копию даёт `xs[::-1]`) |
| `sort()` | сортирует на месте по возрастанию, сортировка устойчивая |
| `clear()` | удаляет все элементы |
| `join(разделитель)` | склеивает элементы в одну строку |

```glass run
fn main() {
    let xs = [5, 3, 8]
    let last = xs.pop()
    print(last, xs)
    xs.insert(1, 42)
    xs.append(7)
    print(xs, xs.indexOf(42), xs.contains(99))
    xs.remove(42)
    xs.sort()
    print(xs)
    xs.reverse()
    print(xs, xs.join("-"))
    xs.clear()
    print(xs, len(xs))
}
```

```output
8 [5, 3]
[5, 42, 3, 7] 1 false
[3, 5, 7]
[7, 5, 3] 7-5-3
[] 0
```

## Функции над массивами

`len`, `sum`, `min`, `max` принимают массив чисел:

```glass run
fn main() {
    let xs = [4, 2, 9]
    print(len(xs), sum(xs), min(xs), max(xs))
    print(sum([1.5, 2.5]))
}
```

```output
3 15 2 9
4.0
```

## Массив — это ссылка

Присваивание копирует **ссылку**, а не содержимое: после `let alias = xs` это два имени одного и того же массива. Независимую копию делает срез `xs[:]`.

```glass run
fn main() {
    let xs = [1, 2]
    let alias = xs
    let copy = xs[:]
    alias.append(3)
    print(xs, alias, copy)
}
```

```output
[1, 2, 3] [1, 2, 3] [1, 2]
```

## Вложенные массивы

```glass run
fn main() {
    let grid = [[1, 2], [3, 4]]
    print(grid, grid[1][0])
    for row in grid {
        print(sum(row))
    }
}
```

```output
[[1, 2], [3, 4]] 3
3
7
```
