# Основы языка

Всё, из чего состоит любая программа на Glass: функция `main`, переменные, типы, операции и вывод. Примеры на этой странице выполняет настоящая VM, а показанный рядом вывод проверяет тест — поэтому документация не может разойтись с языком.

## Программа и `main`

Выполнение начинается с функции `main`. Точки с запятой не нужны: оператор заканчивается концом строки.

```glass run
fn main() {
    print("Привет, Glass!")
}
```

```output
Привет, Glass!
```

`print` печатает аргументы через пробел и переводит строку; `print()` без аргументов печатает пустую строку.

## Переменные

`let` создаёт переменную. Тип можно написать (`let age: int = 36`) или доверить компилятору: он выводится из значения и дальше не меняется. Составное присваивание — `+=`, `-=`, `*=`, `/=`.

```glass run
fn main() {
    let age: int = 36
    let name = "Ада"
    let height: double = 1.68
    let adult = age > 18
    print(name, age, height, adult)
    age += 1
    print(age)
}
```

```output
Ада 36 1.68 true
37
```

Положить в переменную значение другого типа нельзя — ошибка видна до запуска, с номером строки и столбца:

```glass error
fn main() {
    let age = 36
    age = "сорок"
}
```

```output
1 ошибок типизации (тела функций):
  3:11: тип 'string' не совместим с ожидаемым 'int'
```

## Типы

| Тип | Что хранит |
|---|---|
| `int` | целое число (64 бита) |
| `double` | вещественное число |
| `bool` | `true` или `false` |
| `string` | текст (Юникод, кириллица работает) — см. [строки](strings.md) |
| `[T]` | массив элементов типа `T`, например `[int]` — см. [массивы](arrays.md) |
| имя `mold` | объект — см. [объекты](objects.md) |

Целые делятся нацело, `%` — остаток. Если хотя бы один операнд `double`, результат тоже `double`; вещественные числа печатаются с точкой.

```glass run
fn main() {
    print(7 / 2, 7 % 2, 7 / 2.0)
    print(2 + 3 * 4, (2 + 3) * 4)
    let d: double = 3
    print(d)
}
```

```output
3 1 3.5
14 20
3.0
```

## Сравнения и логика

`==`, `!=`, `<`, `>`, `<=`, `>=` дают `bool`; `&&`, `||`, `!` — логические «и», «или», «не». Правая часть `&&` и `||` вычисляется **только если она нужна** (ленивое вычисление): в примере `noisy` вызывается не всегда.

```glass run
fn noisy(label: string) -> bool {
    print("вычисляю", label)
    return true
}

fn main() {
    print(false && noisy("A"))
    print(true || noisy("B"))
    print(true && noisy("C"))
}
```

```output
false
true
вычисляю C
true
```

## Преобразования типов

`int(x)`, `double(x)`, `bool(x)`, `str(x)` (то же — `string(x)`) — обычные вызовы; можно и в стиле C: `(int) x`. Дробная часть отбрасывается в сторону нуля.

```glass run
fn main() {
    print(int("42") + 1)
    print(int(3.99), (int) -2.7)
    print(double("2.5") * 2)
    print(str(5) + "!")
    print(bool(0), bool("true"))
}
```

```output
43
3 -2
5.0
5!
false true
```

Строка, которая не похожа на число, — ошибка выполнения:

```glass run
fn main() {
    print("до")
    print(int("abc"))
}
```

```output
до
Ошибка выполнения: main:3: не удалось преобразовать строку "abc" в int
```

## Строки и числа вместе

Если одна из сторон `+` — строка, число превращается в текст:

```glass run
fn main() {
    let n = 42
    print("Ответ: " + n)
}
```

```output
Ответ: 42
```

## Константы

`PI` и `E` — встроенные константы типа `double`. Остальные математические функции (`abs`, `sqrt`, `pow`, `floor`, `ceil`, `round`, `min`, `max`) перечислены в [справочнике](../reference/language-reference.md).

```glass run
fn main() {
    let r = 2.0
    print("площадь круга:", PI * r * r)
    print(sqrt(16.0), pow(2, 10), abs(-3), round(2.5))
}
```

```output
площадь круга: 12.5663706143592
4.0 1024.0 3 3
```
