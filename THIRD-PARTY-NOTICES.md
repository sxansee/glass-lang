# Сторонние компоненты

Glass Studio (WPF-оболочка) использует:

- **AvalonEdit** — редактор кода с подсветкой синтаксиса, https://github.com/icsharpcode/AvalonEdit.
  Распространяется по лицензии MIT; полный текст лицензии и сведения об авторских правах — в репозитории проекта
  и в пакете NuGet `AvalonEdit`.

Остальной код (компилятор, VM, C API, ядро IDE) написан в рамках проекта и распространяется по лицензии MIT (см. `LICENSE`).
Самодостаточная сборка Glass Studio включает среду выполнения .NET (лицензия MIT, © .NET Foundation и участники).
